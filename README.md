# TooLight 💡

TooLight (originally Light.io) is a playful **lightweight utility web app** built to run entirely in the browser.  
It started with light and color experiments, but has grown into a small collection of fast, simple tools designed for quick use and exploration.

It’s part practical toolkit, part creative sandbox.

⚠️ This project is currently in active development, so you may encounter occasional quirks or unfinished features.

---

## What is TooLight?

TooLight is a collection of **lightweight, client-side utilities**, including:
- Brightness and full-screen light tools
- Color and HSL-based generators
- Theme and contrast helpers
- Small everyday utilities
- Visual experiments built just for fun

Some tools are genuinely useful, others exist purely for experimentation and inspiration.

---

## Why “TooLight”?

The idea behind TooLight is simple:
- tools should load instantly
- work without setup
- and stay out of your way

I wanted one place to quickly build and test small ideas — without turning everything into a full product.

It’s a space to:
- experiment freely  
- tweak visuals  
- test ideas fast  
- enjoy building UI without pressure  

---

## How it runs

- Fully **client-side**
- Runs directly in the browser
- No backend
- No accounts
- No tracking
